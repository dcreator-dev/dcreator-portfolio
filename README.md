## 🇺🇸 About
This is the live portfolio you see at [dcreator-dev.github.io](https://dcreator-dev.github.io/). Built from scratch with vanilla HTML/CSS/JS — no frameworks, no templates. Features include:

- Animated mesh-gradient background with particles
- Interactive **Before/After slider** for case studies
- 3D tilt cards with spotlight cursor effect
- Magnetic CTA buttons
- Scramble text effect on headlines
- Animated counters (years, projects, retention)
- Marquee tech stack
- FAQ accordion
- Full RU/EN language switch
